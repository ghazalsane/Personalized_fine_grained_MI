# Personalized fine-grained motor imagery

Research implementations in `run_shallow_all.py` and `run_personalized.py`.

The completed Perlmutter ShallowConvNet baseline is documented in
[results/shallowconvnet/job-61441374](results/shallowconvnet/job-61441374/README.md),
including publication figures, summary tables, exact run provenance, and
verification against the original output. Both original training scripts are
unchanged.

To regenerate figures or verify the publication package without training, see
[the result reproduction commands](results/shallowconvnet/job-61441374/README.md#regeneration-and-verification).
EEG data and binary checkpoints are excluded from this repository.
